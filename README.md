# 🌦️ Weather X

A modern weather web app with real-time API data, city search, animated UI, and Google Maps integration.


## 🚀 Live Demo
👉 https://codeboy-710.github.io/weather-x/

## ✨ Features

- 🌍 Real-time weather data using WeatherAPI
- 🔎 City search with autocomplete suggestions
- ⏱ Local, GMT, and Pacific time display
- 🗺 Google Maps integration for selected cities
- 🖼 Dynamic city image fetching
- 🎨 Modern animated UI with gradients and effects
- 📱 Responsive design

---

## 🛠 Tech Stack

- HTML5
- CSS3 (Flexbox, Animations, Gradients)
- JavaScript (Vanilla JS)
- WeatherAPI
- Google Maps Embed API
